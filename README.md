📋 Task Manager - React

Aplicação web desenvolvida em React para gerenciamento de tarefas, permitindo adicionar, visualizar e organizar atividades de forma simples e intuitiva.
Os dados são armazenados utilizando um servidor fake com JSON Server, simulando uma API REST para manipulação das informações.

🚀 Tecnologias utilizadas
• React
• CSS
• JSON Server
• JavaScript (ES6+)
• Fetch API

✨ Funcionalidades
• Criar novas tarefas
• Adicionar duração/tempo estimado
• Listar tarefas cadastradas
• Remover tarefas
• Marcar tarefas
• Integração com API fake usando JSON Server

🎯 Objetivo do projeto

Este projeto foi desenvolvido com foco em praticar:

• Consumo de API REST
• Manipulação de estados no React
• Componentização
• CRUD completo
• Organização de projeto Front-End
